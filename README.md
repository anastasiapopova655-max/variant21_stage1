# Вариант 21 — Этап 2: параметры запуска и стартовый скрипт

Продолжение первого этапа эмулятора UNIX-подобной командной оболочки на Python/Tkinter.

## Реализовано

- сохранён GUI из этапа 1;
- параметры командной строки для пути к VFS и стартовому скрипту;
- поддержаны варианты `--vfs` / `--vfs-path` и `--script` / `--startup-script`;
- стартовый скрипт выполняется последовательно при запуске программы;
- пустые строки и строки с `#` в стартовом скрипте пропускаются;
- каждая выполняемая команда и её результат выводятся в интерфейс;
- ошибка одной команды стартового скрипта не останавливает выполнение следующих команд;
- ошибка отсутствующего или нечитаемого стартового скрипта выводится пользователю;
- добавлена команда `conf-dump`, выводящая конфигурацию в формате `ключ=значение`;
- `ls` и `cd` сохранены как заглушки первого этапа;
- добавлены автоматические тесты этапа 2.

## Запуск

Требуется Python 3 и Tkinter.

Обычный запуск:

```bash
./run.sh
```

Запуск с путём VFS:

```bash
./run.sh --vfs disk.vfs
```

Запуск со стартовым скриптом:

```bash
./run.sh --vfs disk.vfs --script startup.txt
```

Также поддерживаются длинные варианты параметров:

```bash
./run.sh --vfs-path disk.vfs --startup-script startup.txt
```

## Стартовый скрипт

Пример `startup.txt`:

```text
ls
unknown command
conf-dump
cd home
```

Программа выполнит строки по порядку. Ошибка `unknown command` будет выведена, но следующие строки продолжат выполняться.

## conf-dump

Команда:

```text
conf-dump
```

выводит конфигурацию:

```text
vfs_path=disk.vfs
startup_script=startup.txt
```

## Тесты

```bash
python3 -m pytest
```

Тесты проверяют параметры запуска, `conf-dump`, стартовый скрипт и продолжение его выполнения после ошибки.
